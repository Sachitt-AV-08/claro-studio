# @project/components — owned by Agent 4

Landing-zone for the curated Claro component/effect collection (Hero, Feature Grid, Pricing
Card, Navbar, Modal, Input/Form, Aurora/Particles effects, ...). Components are REAL Claro
program constructs: `.cl` component files + schema registration (contracts/src/dsl-schema.ts)
so they render, inspect, and AI-edit like any built-in element. Never giant pasted code.

This package hosts registry + bundled `.cl` sources; components can also live in user projects.
